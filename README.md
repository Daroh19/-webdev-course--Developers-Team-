# Curso de Fundamentos de Desarrollo Web (HTML y CSS)

Bienvenidos al repositorio del curso de desarrollo web enfocado a estudiantes de secundaria, creado por el equipo Developers-Team.

Este repositorio contiene todo el código fuente que se utilizo a lo largo de las lecciones en video.

## Instrucciones de Configuración y Uso

Para seguir este curso no necesitas instalar nada en tu computadora, solo tu navegador web. El código fuente está organizado en las siguientes carpetas para facilitar tu aprendizaje:

* **/starter-files**: Aquí encontrarás el código base incompleto para cada lección. Puedes copiar este código y pegarlo en tu editor en línea (como CodePen o JSFiddle) para empezar a programar junto con el video.
* **/completed-examples**: Contiene el código HTML y CSS 100% finalizado de cada práctica. Úsalo como referencia si te estancas o quieres comparar tu resultado final.
* **/scripts**: Scripts y recursos adicionales del sistema.
